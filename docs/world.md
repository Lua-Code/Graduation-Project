# World, Scenario & Damage (Module B)

Road graph, travel times, routing and earthquake road damage. Code lives in
`src/drsim/simulation/world/`. All functions here are pure: they read the map and the
current edge states and never modify simulation state. The engine owns
`SimulationState.edge_states` and applies changes.

## Road graph and travel time (`graph.py`)

- Vehicles move only on the road graph. Incidents and hospitals sit on road nodes.
- Edge travel time in ticks = `ceil(lengthMeters / speedMetersPerSecond / tickDurationSeconds)`,
  minimum 1 tick (D13, D14). Example: 800 m at 13.9 m/s = 57.6 s = 6 ticks.
- `BLOCKED` edges are never used. `DEGRADED` edges take `DEGRADED_TRAVEL_MULTIPLIER` (2)
  times as long ([ADR-0002](adr/0002-degraded-road-travel-multiplier.md)).
- Tie-break between equal-cost routes: fewest ticks, then lexicographically smallest
  node-ID path, then smallest edge-ID path. Routes never depend on map file order.

| Function | Caller | Purpose |
|---|---|---|
| `RoadGraph.from_map(map_def)` | all | Build static topology once |
| `edge_travel_ticks(edge, state, tick_seconds)` | engine | Ticks for one edge, `None` if blocked |
| `shortest_route(graph, edge_states, a, b, tick_seconds)` | engine, incidents | `Route` or `None` |
| `is_reachable(...)` | dispatch | Backs `ROUTE_INFEASIBLE` |
| `travel_ticks_matrix(graph, edge_states, origins, destinations, tick_seconds)` | AI | Travel-time matrix |

## Earthquake road damage (`hazards/road_damage.py`)

**Illustrative rule, not physics.** Parameters are not calibrated to real earthquakes.

Rule `road-damage-1.0` (parameters in `RoadDamageRule`, all **provisional**):

1. Affected radius = `300 m × (magnitude − 4.0)`; magnitude 6.5 gives 750 m.
2. `closeness = 1 − distance / radius` (0 outside), using the shortest distance from the
   epicentre to the road segment.
3. Damage probability `p = initialDamageScale × closeness`. One draw `u`:
   `u < 0.4·p` → `BLOCKED`, `u < p` → `DEGRADED`, otherwise undamaged.
4. A road `DEGRADED` at tick 0 collapses to `BLOCKED` with probability 0.25, at a tick
   drawn uniformly from 30–180 (5–30 simulated minutes).

Determinism:

- `generate_road_damage_schedule(scenario, map_def, rule)` runs once at scenario load and
  returns a fixed `RoadDamageSchedule`. Ticks only read it (D3, D8).
- It uses its own RNG seeded from `"{seed}:road-damage"`, so other random draws (for
  example victim health) never change road damage, and it does not depend on
  `PYTHONHASHSEED`.
- Edges are processed in sorted ID order and each consumes exactly three draws.
- Damage only worsens a road; it never repairs one.

### Engine integration (tick phase 5)

```python
changes = road_changes_at(schedule, state.edge_states, state.tick)
for change in changes:  # already in stable edge-ID order
    state.edge_states[change.edge_id] = change.new_state
    # record EventType.EDGE_STATE_CHANGED with change.edge_id, old/new state, cause
```

Tick-0 damage is applied in the first hazard phase. Routing and movement later in the
same tick see the new road states.
